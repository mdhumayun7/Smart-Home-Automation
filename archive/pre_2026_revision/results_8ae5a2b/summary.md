## H1 (logical form): safety latency is invariant to attack rate

**Read this with its caveat.** In simulation the device clock is advanced by the harness, so there is no CPU contention and the latency is deterministic: the variance is zero and the test below is trivially satisfied. What this establishes is the *logical* claim, that no code path makes the safety response depend on network input. The *timing* claim (H1 proper) can only be tested on hardware, where the radio driver and the safety loop genuinely contend; the same test is applied to that data in `experiments/hardware/`.

Mann-Whitney U, two-sided, each attack rate against the no-attack control.
